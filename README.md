## 📝 서비스 소개

-   현재 대학생, 입문자들에게 학교 수업외에 개발 프로젝트를 진행하는데 어려움을 겪는다는 문제점을 공감하게 되었고, 이를 해결하기 위해 기획/디자인, 백엔드, 프론트엔드 등 각 파트에 
맞춰 프로젝트에 대한 기초적인 정보를 얻고, 본인의 개발 일정 등을 공유할 수 있는 대학생, 입문자 대상 커뮤니티 서비스를 개발하고자 하였다.
